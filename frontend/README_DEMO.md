## 🚀 Guía Rápida de Uso

### **1. Acceder al Demo:**
1. Abrir navegador en `http://localhost:5173/demo`
2. Ingresar credenciales: `demo@8amperios.com` / `Demo2024!`
3. Explorar el dashboard principal

### **2. Explorar CRM:**
1. Ir a "Dashboard" → "CRM"
2. Ver lista de clientes pre-cargados
3. Explorar cotizaciones existentes
4. Crear nueva cotización de prueba

### **3. Probar Cotizador:**
1. Ir a "Cotizador Profesional"
2. Seleccionar cliente existente
3. Agregar productos desde inventario
4. Ver cálculos automáticos
5. Generar vista previa

### **4. Diseñar Transformador:**
1. Ir a "Dashboard" → "KAVE"
2. Ingresar parámetros técnicos
3. Ver resultados de diseño
4. Explorar cálculos detallados

### **5. Crear Formulario:**
1. Ir a "Diseñador Formularios"
2. Arrastrar componentes al canvas
3. Configurar propiedades
4. Guardar diseño
