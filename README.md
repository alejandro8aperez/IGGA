# 🏭 ERP 8AMPERIOS

Sistema Integral de Gestión Empresarial (ERP) diseñado para la optimización de procesos industriales, comerciales y de servicios. Especializado en el sector de transformadores y panadería.

## 🚀 Módulos Principales

*   **CRM Avanzado:** Gestión de clientes, oportunidades y documentos adjuntos.
*   **Ventas y Facturación:** Control de órdenes, facturación electrónica (DIAN) y edición de unidades.
*   **POS Panadería:** Punto de venta rápido con categorías optimizadas.
*   **KAVE (Simulador Físico):** Planificador analítico para diseño de transformadores.
*   **MRP:** Planificación de requerimientos de materiales y manufactura.
*   **Inventarios:** Control de stock con alertas de bajo inventario.
*   **Contabilidad y Finanzas:** Balance general, estados de resultados y tesorería.
*   **RRHH y Nómina:** Gestión de empleados y generación de vouchers.

## 🛠️ Tecnologías

*   **Backend:** Django 5.x & Django REST Framework.
*   **Frontend:** React 18 (Vite) con diseño moderno y Lucide Icons.
*   **Base de Datos:** PostgreSQL.
*   **Infraestructura:** Preparado para despliegue en Render/AWS.

## 📦 Instalación Local

1. Clonar el repositorio.
2. Configurar entorno virtual de Python y `pip install -r requirements.txt`.
3. Instalar dependencias de frontend: `cd frontend && npm install`.
4. Configurar variables de entorno en `.env`.
5. Ejecutar migraciones: `python manage.py migrate`.
